## 1. `rescan` orchestration — commit edcefe8 (net.py only)

One command: stop → `set_config scan` → `detect_imu` census → pick the fabric
(both IMUs → aimuboth, A/B-only → aimu_a/_b, none → acquisition) →
`set_config` it → existing `auto_cable_detect` phase sweep sets phases + mask.
`rescan noapply` skips the sweep. Key survey result baked into the header
comment: READ_REGISTER/'INTAN'-ROM reads are **port A only** (status reg 12),
so the 4-lane phase sweep is the only per-cable chip probe — no new firmware
needed. Also fixed en route: a stale duplicate `print_command_help` was
shadowing the maintained menu (IMU/PL lines were invisible at runtime).

**Biggest open question:** is it safe to drive I2C into a port whose headstage
is 128-ch LVDS (scan fabric probes both ports blindly)? Also: should two empty
ports load `acquisition` or stay on `scan`?

## 2. Headstage EEPROM — commit 55526f2 (docs/headstage-eeprom.md, no firmware)

Carrier KiCad has no EEPROM/BNO055 → they're on the headstage, schematic not in
these repos → written proposal only. Best guess: 24xx at 0x50–0x57 on the same
freed-CIPO bus. Trap documented: a 24LC16 block-addresses ALL of 0x50–0x57, so
"8 ACKs" may be one chip. Proposal: per-port `CMD_I2C_SCAN` (0xB7) bitmap probe,
then `CMD_EEPROM_READ`. **Needs from you:** part number + WP strapping from the
schematic, and whether we define the identity-record format.

## 3. IMU ingestion — commit 0bff590 (firmware + net.py + docs/imu-ingestion.md)

Testable now: `set_config acq_imu_both` → `imu_read a` → quaternion/accel/gyro/
calib/temp (enters NDOF on first read, ~50 ms; refused while streaming; per-port
IIC-gated). `blobs/BOOT.bin` rebuilt (`--app-only`, fabrics reused;
`pl_imu_read_sample` verified linked). The design doc is the real deliverable:
continuous 100 Hz readout as a non-blocking AXI IIC FIFO state machine in the
main loop + UDP stream_type=3, one datagram per fused sample, PL-timestamped.
**Decide before it gets built:** fused 100 Hz vs raw-at-1-kHz, calibration
persistence (EEPROM?), whether IMU streaming outlives neural `stop`.
